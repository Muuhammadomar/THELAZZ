# THELAZZ
THELAZZ is a Street vendor marketplace platform connecting local businesses with customers, Built to help and improve neighbourhood vendors establish an online presence, showcase their businesses, and reach more customers. 

🌟 Project Overview

Many local street vendors rely on traditional methods to reach customers. THELAZZ aims to bridge this gap by bringing local markets into the digital world.

With THELAZZ, customers can discover neighbourhood businesses while vendors can register their businesses and build their online presence.

✨ Features

🛍️ Modern and responsive marketplace homepage

🏪 Vendor registration form

🗄️ Supabase database integration

🔐 Supabase authentication setup

📍 Business location and category registration

🎨 Clean and user-friendly interface
